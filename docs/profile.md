# Profile

Open **Profile** from the user menu. The page has four sections.

## Profile

Name, phone, and email. Sign-in keeps using the current address until you open the confirmation link sent to the new one. The link lifetime is **Email confirmation** in portal settings.

## Password

The form asks for the current password and the new one twice. The rule on the form is the live one (by default at least 12 characters, with lower case, upper case, a digit, and a symbol). Saving it signs other sessions out and forgets browsers you marked as trusted for the email code. This browser stays signed in.

**Forgot your password** on the sign-in page emails a reset link to an existing, unblocked account. The page then shows the same confirmation for every address.

## Notifications

Three switches, applied to every ticket:

| Switch                    | Email when                                                                                                                                     |
| ------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| New tickets               | Someone creates a ticket in a project where you are staff. For a client, when the team creates one and the project allows client notification. |
| Replies                   | A new comment appears on a ticket you take part in                                                                                             |
| Status, type and priority | Those fields change on a ticket you take part in                                                                                               |

An unsubscribe link in a message turns the matching switch off.

## Appearance

Language, date format, and time zone are saved on the account.

- **Language** — English or Polish. English is the default.
- **Date and time format** and **time zone** — how timestamps are shown to you.

Theme, depth, spacing, and font size are saved in this browser only.

- **Color theme** — six pairs. Each pair is the same palette in a light and a dark scheme.
- **Background gradient** — Depth (soft glow) or Flat.
- **Spacing** — Tight, Balanced, or Airy.
- **Font size** — Compact, Natural, or Large.
